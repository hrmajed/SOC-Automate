# INC-2025-0147: Encoded PowerShell on build server (false positive)

## Summary
The EDR rule EDR-ENCODED-PS fired on BLD-CI-01 at 02:00 UTC. The analyst confirmed that the nightly Jenkins
artifact-signing job runs `sign-artifacts.ps1` through `powershell.exe -EncodedCommand` so that the signing
certificate path is not written to the job log. The parent process is always `java.exe -jar C:\jenkins\agent.jar`
running as HELIX\svc-ci, and the only network destination is the internal artifact store ARTIFACTS-01 (10.30.2.50).

## Verification checklist used
- Parent process is the Jenkins agent (java.exe) and the user is svc-ci.
- Decoded command runs `C:\build\sign-artifacts.ps1` only.
- No external network connections and no credential access observed.
- Timing matches the 02:00 UTC schedule.

## Disposition
Benign / false positive. Tuning ticket DET-311 opened to suppress EDR-ENCODED-PS when parent=java.exe AND host=BLD-CI-01.
Any encoded PowerShell on BLD-CI-01 that does NOT match these conditions must still be treated as suspicious.
